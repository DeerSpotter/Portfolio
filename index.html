Vault PDF History Export

Turn scattered engineering history into a reviewable workflow.

03 / AI product development · Public source

ContextPort

Changing AI tools should not mean rebuilding your context.

The problem
Useful decisions and project history become fragmented across AI conversations and providers. Repeating the background interrupts the work.
My decision
Make context a portable, revisioned record. Keep provider sessions isolated and give the user control over what travels to the next conversation.
The evidence
The iOS source includes device-local Memory, Markdown and PDF exports, revision history, and sharing across five AI providers. Conversation capture requires evidence of message roles and rejects unsafe captures when a provider's interface changes.

The engineering choice: preserving the integrity of context is part of the product, alongside making it easy to move.

04 / Runtime engineering · Active open-source fork

ipaSim

Change the system at the boundary causing the failure.

The problem
A runtime built for one operating system can contain paths and links another cannot reproduce. Repeatedly extracting the same files does not solve that mismatch.
My decision
Help advance an immutable image-backed read path, so the Windows loader can read the runtime directly. Keep generated calling information separate from approval that a host implementation behaves correctly.
The evidence
Merged PR #78 demonstrates the Windows loader reading real frameworks from a complete DwarFS runtime image without mounting or extracting it. The probe reaches a documented unresolved import: a concrete storage milestone, with compatibility work still in progress.

I am extending the active fork with AI-assisted development. Jan Joneš's original ipaSim research remains its foundation. The project is ongoing; this is evidence of a specific working boundary.

In my simulation work, maps, asset relationships, coverage, and source references need to support the same decision. In a review tool, the record, its history, and the next action need to stay connected. I think about what a person needs to understand at the moment they have to act.
